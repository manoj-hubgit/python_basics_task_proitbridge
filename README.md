### Task 3 – Rock-Paper-Scissors Game

A simple interactive game where the player competes against the computer.

**Concepts Practised:**
- User Input and Output
- Conditional Statements
- Random Module
- Loops
- Exception Handling

**Features:**
- Player selects Rock, Paper, or Scissors.
- Computer randomly selects its choice.
- Determines the winner.
- Allows the player to play again.
- Handles invalid inputs.

### Task 4 – Word Guessing Game (Mini Hangman)

A word-guessing game where the player tries to identify a randomly selected hidden word by guessing one letter at a time.

**Concepts Practised:**
- Loops
- Conditional Statements
- String Manipulation
- Exception Handling
- Logical Thinking

**Features:**
- Random word selection.
- Displays hidden letters as blanks.
- Accepts one-letter guesses.
- Tracks incorrect guesses with a maximum of 6 attempts.
- Ends when the player guesses the word or runs out of attempts.
